Начинаю создание базовой прототипной версии игры GunShot на чистом HTML/JS: главное меню с кнопками Играть, Настройки и Друзья; экран игры с простым игровым циклом; экран настроек; экран Друзья с добавлением по ID и локальным сохранением ID. Сейчас добавлю файлы index.html, style.css, main.js и README.md с кратким объяснением.

Готово. Я создал базовую прототип-структуру игры GunShot с главным меню, игрой, настройками и секцией Друзья, включая систему генерации и отображения ID и возможность добавлять друзей по ID.

Что сделано

  • Созданы файлы проекта:
    • index.html — основная разметка и структура экранов
    • style.css — базовая стилизация главного меню, экранов и канваса
    • main.js — логика приложения:
      • Главная навигация между меню, игрой, настройками и друзьями
      • Генерация уникального ID устройства пользователя (id GunShot) и сохранение в localStorage
      • Секция Друзья: возможность добавлять друзей по их ID и сохранять список в localStorage
      • Простая игровая механика на канвасе: перемещение игрока, стрельба, враг, столкновения, счёт и здоровье
    • README.md — краткая инструкция и описание функционала

Как запустить

  • Откройте файл index.html в любом браузере (локально). Приложение работает полностью в браузере и хранит данные в localStorage, чтобы сохранять ID и список друзей между сеансами.

Кратко о функциональности

  • Главное меню:
    • Играть
    • Настройки
    • Друзья
  • Настройки
    • Переключатель звука (визуально, без встроенного аудио пока)
  • Друзья
    • Поле ввода ID друга, кнопка Добавить
    • Список добавленных друзей (локальное сохранение)
    • Мой ID, отображаемый вверху и в секции Друзья
  • Игровой экран (Canvas)
    • Управление игроком стрелками/A-стрелки
    • Пробел/Enter для выстрела
    • Враг движется вверху; если попадает по нижней части, игрок теряет здоровье
    • Очки за противников, окончание игры по Health
    • При завершении показывается уведомление и возвращение в меню

Файлы и ключевые части кода

  • index.html
    • Структура экранов: menu, game, settings, friends
    • Кнопки: Играть, Настройки, Друзья, Назад
  • style.css
    • Простой, адаптивный стиль
    • Стили для кнопок, списков друзей и канваса
  • main.js
    • Немедленно инициализирует ID, отображает его в интерфейсе
    • Управление состояниями экранов через show()
    • Управление друзьями через localStorage (gunshot_friends)
    • Игровой цикл: простая аркада на canvas (игрок, пули, враг, столкновения)
    • Простая система ввода и перезапуск игры

Что можно улучшить далее (по вашему запросу)

  • Добавить полноценную графику и спрайты вместо простых примитивов
  • Расширить геймплей: больше врагов, ярлыки и уровни, саб-системы оружия
  • Внедрить сетевую кооперацию или PvP (на следующем этапе)
  • Подключить аудио: звуки выстрелов, взрывов, музыка
  • Сохранение прогресса и друзей на сервере (для мультиплеера или синхронизации)
  • Добавить тесты и сборку для продакшн-окружения

    • Взрыв бомбы (радиальная анимация)
    • Над Bomb изображается текст “C4”
    • После взрыва появляется упрощенная silhouette спецназа
  • Анимация запускается автоматически при загрузке страницы и перезапускается каждый раз, когда возвращаетесь в меню.
  • При начале игры превью останавливается, чтобы не конфликтовать с игровым циклом. После возвращения в меню превью запускается снова.

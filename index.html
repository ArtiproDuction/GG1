Как это собрать и запустить (практический план)

  1. Основные зависимости
  • Unity 2020.3+ (или актуальная версия вашего проекта).
  • Mirror пакет (Asset Store или через Package Manager). Это ваш сетевой слой вместо Photon/EMS в демо.
  • Префабы игроков должны содержать: PlayerNetworkIdentity, PlayerController, WeaponSystem, HealthSystem, CameraController и, по желанию, UI-элементы.
  1. Структура сцены и префабы
  • Сцена лобби (LobbyScene):
    • Добавьте сетевой менеджер (NetworkManager + NetworkLobbyManagerExtended).
    • В сцене разместите UI для списка друзей, кнопки “Invite”, кнопку запуска матча.
  • Сцена игры (GameScene):
    • Разместите spawnPoints (Transform[]) для SpawnManager.
    • Разместите игрока-префаб, содержащий PlayerNetworkIdentity, PlayerController, CameraController, WeaponSystem и HealthSystem.
    • Включите NetworkTransform/Sync для базовой синхронизации позиций (если потребуется).
  1. Как работает приглашение по никнейму
  • На сервере хранится сопоставление никнейм → NetworkConnection в NetworkLobbyManagerExtended.NicknameToConnection.
  • Приглашение по никнейму можно инициировать через метод InviteFriend(nickname) на сервере.
  • Сервер отправляет клиенту пригласительное уведомление через TargetLobbyInvite. Реализация UI опциональна: подключите метод UIManager, чтобы показать уведомление и кнопку «Присоединиться».
  • Клиент, приняв приглашение, может перейти в игровую сцену через стандартный переход Mirror (Server -> клиент заходит в сцену).
  1. Как подключить друзей к лобби (пример взаимодействия)
  • На клиенте установите никнейм (через UI) и вызовите CmdSetNickname или через локальный скрипт:
if (isLocalPlayer) {
  GetComponent<PlayerNetworkIdentity>().CmdSetNickname("Alex123");
}
  • Чтобы пригласить друга по никнейму:
NetworkLobbyManagerExtended lobby = FindObjectOfType<NetworkLobbyManagerExtended>();
if (lobby != null) lobby.InviteFriend("FriendNick");
  • Другая реализация: через UI добавить кнопку "Invite" рядом с ником; кнопка вызывает пригласить по нику на сервере.
  1. Режимы и игровые механики
  • Режимы: GameModeManager.mode может быть OneToOne или FFA. В обработке убийств в GameModeManager можно расширить рейтинг и логику победы под ваши требования.
  • Механика стрельбы: WeaponSystemCmdShoot реализует Raycast с учетом дистанции range и урона damage. Hit по различным частям тела можно уточнить, добавив теги/слои на коллайдерах и анализируя hit.collider.tag или hit.collider.gameObject в health-системе.
  • Перезарядка и смена рук: можно добавить UI-настройки и флага isRightHand в оружии; для упрощения базовый пример можно расширять в дальнейшем.
  1. Настройки
  • SettingsManager сохраняет мышь чувствительность, громкость и пр. в PlayerPrefs; можно расширять под разрешения и бинды клавиш.
  • UIManager — заготовки для переключения панелей (меню, лобби, настройки, чат и т.д.).
  1. Сборка и дальнейшее развитие
  • Привязка сетевых объектов в инспекторе (NetworkIdentity на префабе игрока, Collider, Rigidbody/CharacterController).
  • Добавление систем анимаций (1p/3p, бег, присед, попадания) по мере необходимости.
  • Замена части лоббирования на Photon/ESP-решение (Photon Unity Networking) можно сделать позднее, перенесем логику приглашений и лобби под выбранный сервис, сохранив архитектуру — NetworkLobbyManagerExtended, PlayerNetworkIdentity, GameModeManager и пр.

public class PlayerNetworkIdentity : NetworkBehaviour

    [SyncVar] public string nickname = "Player";

    void Start()
    {
        if (isLocalPlayer)
        {
            CmdSetNickname(nickname);
        }

    [Command] public void CmdSetNickname(string name)

        var mouseY = Input.GetAxis("Mouse Y") * mouseSensitivity;
        transform.Rotate(0, mouseX, 0);
        if (cameraTransform != null)
        {
            // простой поворот камеры
            // адаптируйте под вашу иерархию камеры
        }
        velocity.y += gravity * Time.deltaTime;
        controller.Move(new Vector3(0, velocity.y, 0) * Time.deltaTime);
    }
}
  • Raycast-стрельба:
public class WeaponSystem : NetworkBehaviour
{
    public Camera viewCamera;
    public float range = 100f;
    public int damage = 25;
    public float fireRate = 0.2f;
    private float nextTimeToFire = 0f;

    void Update()
    {
        if (!isLocalPlayer) return;
        if (Input.GetButton("Fire1") && Time.time >= nextTimeToFire)
        {
            nextTimeToFire = Time.time + fireRate;
            CmdShoot(viewCamera.transform.position, viewCamera.transform.forward);
        }
    }

    [Command] void CmdShoot(Vector3 origin, Vector3 direction)
    {
        if (Physics.Raycast(origin, direction, out var hit, range))
        {
            var health = hit.collider.GetComponent<HealthSystem>();
            if (health != null)
            {
                var attacker = connectionToClient.identity.gameObject;
                health.TakeDamage(damage, attacker);
            }
        }
    }
}
  • Здоровье и смерть:
public class HealthSystem : NetworkBehaviour
{
    [SyncVar] public int currentHealth = 100;
    public int maxHealth = 100;

    [Server] public void TakeDamage(int amount, GameObject attacker)
    {
        if (currentHealth <= 0) return;
        currentHealth -= amount;
        if (currentHealth <= 0)
        {
            NetworkIdentity victimId = GetComponent<NetworkIdentity>();
            var killerId = attacker?.GetComponent<NetworkIdentity>();
            GameModeManager.Instance?.RegisterKill(killerId, victimId);
            RpcDie();
        }
    }

    [ClientRpc] void RpcDie() { /* локальная смерть */ }

    [Server] public void ResetHealth() { currentHealth = maxHealth; }
}
  • Режимы и убийства:
public class GameModeManager : NetworkBehaviour
{
    public static GameModeManager Instance;
    public enum Mode { OneToOne, FFA }
    [SyncVar] public Mode mode = Mode.OneToOne;
    private readonly Dictionary<NetworkIdentity, int> kills = new Dictionary<NetworkIdentity, int>();

    [Server] public void RegisterKill(NetworkIdentity killer, NetworkIdentity victim)
    {
        if (killer == null) return;
        if (!kills.ContainsKey(killer)) kills[killer] = 0;
        kills[killer]++;
        if (mode == Mode.OneToOne && kills[killer] >= 1)
        {
            RpcEndGame(killer.connectionToClient);
        }
    }

    [TargetRpc] void RpcEndGame(NetworkConnection winnerConn)
    {
        // UI: показать победителя
    }
}

Что дальше

  • Этот каркас — точка старта. Вы можете постепенно заменять часть сервисов на Photon или Epic Online Services, не меняя общую архитектуру:
    • Лобби и пригласительные механики можно перенести на Photon/EMS, но сохраните понятную логику: никнейм → игрок, статусы онлайн/в игре/в меню.
  • Реализация анимаций персонажа (переходы from 1P to 3P, бег, прыжок, попадания) потребует добавления Animator и анимационных состояний; можно расширить на основе текущей структуры.
  • Расширение настроек (ключи привязки, разрешения, качество графики) можно вынести в отдельные конфигурационные скрипты и связать с UI через SettingsManager.

Важные замечания по использованию

  • Namespace: так как классы находятся в неймспейсе UnifiedFPSNetwork, в инспекторе Unity может потребоваться указать полный путь к типу (UnifiedFPSNetwork.NetworkLobbyManagerExtended и т.д.) или, при необходимости, временно убрать пространство имён, чтобы привязки работали в Editor без дополнительных манипуляций.
  • Сетевой движок: файл готов под Mirror. Если вы планируете переход на Photon или Epic Online Services, логику лобби и приглашения можно адаптировать под соответствующий сервис, сохранив общую архитектуру.
  • Не забывайте про сетевые объекты:
    • Префаб игрока должен содержать компоненты: PlayerNetworkIdentity, PlayerController, CameraController (или связанную структуру камеры), WeaponSystem, HealthSystemUnified и пр.
    • Нужно добавить NetworkManager в сцену и настроить базовые параметры (spawnables, лобби-менеджер и т.д.). В текущем файле есть базовый NetworkLobbyManagerExtended, но в Editor нужно убедиться, что он добавлен как компонент (UnifiedFPSNetwork.NetworkLobbyManagerExtended) или убрать пространство имён, если вы хотите более простую привязку в инспекторе.
  • Краткая инструкция запуска
    1. Установите Mirror через Package Manager.
    2. Добавьте файл UnifiedFPSNetwork.cs в проект (Assets/Scripts).
